## ✨ Features & Architecture

- **Interactive Neural Network Hero Canvas**: Physics-based simulated neurons and synapses in HTML5 Canvas with mouse attraction and action potential (pulse) firing.
- **Client-Side AI Playground & Sandbox**: Live Byte-Pair Encoding (BPE) subword tokenizer decomposition, multi-class sentiment analysis confidence scoring, and high-dimensional embedding vector simulation.
- **Categorized Skills Matrix**: Clear breakdown across Deep Learning (PyTorch, Hugging Face), GenAI & LLMs (RAG, LangGraph), Computer Vision (YOLOv8, OpenCV), Vector Databases (Qdrant, Pinecone), MLOps (FastAPI, Docker, MLflow), and Dev tools.
- **Case Study Project Showcase**: Dynamic category filters (`All`, `GenAI & LLMs`, `Computer Vision`, `MLOps & TimeSeries`) highlighting real metrics, architecture details, and GitHub code links.
- **Sleek Dark Tech Aesthetic**: Inspired by modern AI developer platforms (dark obsidian slate palette, glowing neon cyan/indigo gradients, glassmorphism cards).
- **Zero Build Dependencies**: Runs directly in any web browser without needing `npm` or `node`. Fully static and optimized for instant loading.

## 🚀 Live Preview & Running Locally

### Option 1: Direct File Open
Simply double-click `index.html` or open it with your favorite browser:
```powershell
Start-Process "index.html"
```

### Option 2: Local Python Server
Since Python is installed on your machine, you can launch a lightweight local server:
```powershell
python -m http.server 8000
```
Then visit [http://localhost:8000](http://localhost:8000).

## 🌐 1-Click Deployment to GitHub Pages

Since your repository is already located at `https://github.com/sawinkumar13-design/project-`:

1. Commit and push these files to your repository:
   ```powershell
   git add .
   git commit -m "feat: complete AI/ML engineer portfolio"
   git push origin main
   ```

2. Turn on GitHub Pages:
   - Go to your repository on GitHub: `https://github.com/sawinkumar13-design/project-`
   - Click **Settings** → **Pages** (in the left sidebar).
   - Under **Build and deployment** > **Source**, choose **Deploy from a branch**.
   - Under **Branch**, select `main` and `/ (root)`, then click **Save**.
   - Within 1–2 minutes, your portfolio will be live at:
     `https://sawinkumar13-design.github.io/project-/`
